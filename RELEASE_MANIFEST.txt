LEAD PLATFORM — COMBINED OUTREACH MVP

This bundle deliberately combines several previously planned mini-steps:
- User email templates
- Gmail OAuth sender connection
- Encrypted OAuth token storage
- Lead selection → Outreach handoff
- Campaign draft creation
- Message preview
- Explicit approval gate
- Persistent email queue
- Separate worker process
- Gmail API sending
- Daily sending limits
- Sending windows/timezone
- Minimum interval
- Pause/resume/cancel
- Suppression filtering
- Duplicate protection within a campaign
- Basic campaign metrics

New migration:
- backend/migrations/002_outreach.sql

New environment variables:
- FRONTEND_APP_URL
- GMAIL_OAUTH_CLIENT_ID
- GMAIL_OAUTH_CLIENT_SECRET
- GMAIL_OAUTH_REDIRECT_URI

No new Python package dependency is required for Gmail; OAuth and Gmail REST calls use existing httpx.

Local sending requires a third process:
- python -m app.outreach.worker

Preserve locally:
- .git/
- backend/.env
- backend/.venv/
- frontend/.env
- frontend/package-lock.json
- frontend/node_modules/

Never change or lose:
- CREDENTIAL_ENCRYPTION_KEY

First send test must use one recipient email you control.
