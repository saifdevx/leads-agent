LEAD PLATFORM RELEASE MANIFEST
==============================
VERSION: 0.2.0
CHECKPOINT: 2 — Firebase Authentication

PURPOSE
-------
Add a complete but deliberately simple authentication layer to the stable v0.1.1 application foundation.

USER-FACING FEATURES
--------------------
- Login
- Registration
- Google sign-in
- Forgot-password email
- Logout
- Persistent Firebase session
- Protected application shell
- Account identity in header

SERVER SECURITY
---------------
- Frontend Firebase authentication is not trusted by itself.
- Firebase ID tokens are sent as Bearer tokens to FastAPI.
- FastAPI verifies tokens with Firebase Admin.
- Protected identity endpoint: GET /api/v1/auth/me
- Missing/invalid tokens are rejected.
- Missing server credentials prevent protected app access.

DEPENDENCY CHANGES
------------------
FRONTEND ADD:
- firebase==12.19.0

BACKEND ADD:
- firebase-admin==7.5.0

NO DATABASE
